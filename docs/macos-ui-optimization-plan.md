# macOS 工作台 UI 优化计划

评审对象为 004 工作台原型及正式 App 已复用的组件。依据 [Apilot macOS 界面规范](standards/apilot-macos-ui.md) 和 [macOS App UI 指南](standards/guides/macos-app-ui-guide.zh-CN.md)。本次对照浅色窗口截图、渲染代码和交互测试。下列工作包用于后续实施。

本文记录初次评审的基线及实施计划。当前界面和验收路径见[工作台使用指南](workbench.md)。

## 评审基线

| 范围 | 评价 | 依据与影响 |
| --- | --- | --- |
| 窗口与导航 | 结构符合，层级需改 | 50 pt 工具栏、200 pt 侧栏、独立设置窗口和 300 pt 详情已落地。四个导航项全部加粗，主区再无条件重复当前去向，首屏出现多个同等醒目的起点。见 [窗口与页面](../desktop/internal/ui/workbench/workbench.go)。 |
| Now 与全局助理 | 交互可用，视觉优先级偏离最大 | 首句 16 pt、正文 14 pt，消息间距 22 pt。每条助理消息重复星光底块与作者，引用使用完整按钮，输入框内外各有边界。阅读事实、查看依据、改变关注状态三件事的差别要靠读完标签才清楚。见 [Now](../desktop/internal/ui/workbench/now_chat.go) 和 [消息与输入组件](../desktop/internal/ui/components/conversation.go)。 |
| 任务表与详情 | 集合浏览符合，字段展示需改 | 原生表格支持列排序、键盘选行和窄窗返回。详情中对象标题 18 pt，摘录 13 pt；已确认截止日用成功色，日期在文本和选择器中重复，保存按钮常驻。稳定事实与需要决策的冲突使用同样的面板边框。见 [任务详情与回写](../desktop/internal/ui/workbench/workbench.go)。 |
| 连接与定时任务 | 最接近基线 | 两页都围绕具体对象排布。连接状态紧邻确认时间，异常行有重连入口，但每行再占一排展示详情和查看任务两个按钮。定时任务已将计划、运行结果和独立运行命令放在一行；双行容器固定 54 pt，需验证放大文字和长标题。见 [定时任务](../desktop/internal/ui/workbench/scheduled_tasks.go)。 |
| 设置与调试 | 区域归属符合，设置字段层级弱 | 设置的三块内容均有外框和同级粗标题；「助手库　知识库　写作库　记忆」是一串静态文本，无法看出各项当前配置。调试已在右上角浮层，ChangeTag 可切换，适合继续承载评审场景。 |
| 色彩、复用与验收 | 主题已集中，使用规则落实不齐 | 暖灰底、白色内容面、珊瑚强调色已集中在[主题](../desktop/internal/ui/components/theme.go)。主要偏差是普通字段使用成功色、普通内容过度围合。组件预览已复用工作台表格和详情；打包后的 VoiceOver 体验待实测。 |

## 分批实施

以下每行可作为一个独立变更评审。先用 Now 验证公共规则，再扩到其余区域。涉及共用组件时，同时检查原型和正式 App 的调用点。

| 顺序与依赖 | 修改位置及动作 | 完成条件 |
| --- | --- | --- |
| 1 · 字体与窗口 | 在 `internal/ui/components` 落地规范中的五个文本角色，沿用官方控件指标。将 `workbench.go` 中未选中导航恢复为常规字重；按页面决定是否显示页标题。整理自绘组件中的 9、15、22 pt 等间距为规范档位。 | 并排检查宽窄窗，导航选区清楚，任务对象与正文成为各自主区的第一层。系统焦点环和表格失焦反馈可辨。 |
| 2 · Now 和助理，依赖 1 | 调整 `now_chat.go`、`conversation.go` 及全局助理。打开 Now 先呈现「周五答复客户前，退款验收仍在进行」，接两条链接式来源和一个「关注退款验收」主动作。时间随消息组展示。星光保留在全局入口，输入器只保留一层编辑边界。两处对话复用引用和输入器。 | 首屏无需输入即可识别事项、依据和决定。两条引用能用 Tab、Return 分别打开对应原文；返回后草稿、读到的位置仍在，关注后只显示一次对应状态。两轮追问可读、可滚动。 |
| 3 · 字段与回写，依赖 1，可与 2 并行 | 在 `workbench.go` 的任务详情中按「对象 → 事实 → 证据 → 字段」组织内容。已确认时仅显示中性色截止日和编辑入口，进入编辑才出现日期选择、保存、取消。待确认原位列出两值，冲突时显示选择，未知时提供核对。复用组件预览的状态切换。 | 已确认时日期只出现一次。修改后取消能恢复原值，提交后的两值在 300 pt 详情和窄窗均可读。筛掉对象即关闭详情，返回列表保持行、排序和焦点。 |
| 4 · 连接、自动化与设置，依赖 1 | 连接行用展开控件查看元数据，保留直达来源任务和异常恢复动作。定时任务双行高度按内容增长，长标题可取得全文。设置用 MyGo 表单分组，模型可选；资料逐项显示已知配置或「未配置」。原型凭据与权限状态使用明确的演示标识。 | 两个工作区与一个离线来源可辨，重连后历史时间准确。长任务名下仍可定位对应运行按钮。设置可一眼区分可编辑值与只读信息。调试标记关闭时，主界面没有评审标签。 |
| 5 · 回归，依赖 2–4 | `component_gallery.go` 使用同一批工作组件检查长中文、无日期、空集合、多来源和多轮对话。更新受交互变化影响的 `workbench_test.go`，对共用任务行补查正式 App。 | 交付下节中的前后截图、回归结果与辅助功能实测记录。逐项列出仍待验证的场景。 |

## 验收与交付

在仓库根目录运行。实施前保留一份基线截图，各批次将输出目录换成对应批次名。

```sh
go run ./cmd/apilot-app --mock --capture tmp/ui-baseline
go test -count=1 ./internal/ui/...
go test ./...
make check-format check-architecture
```

- 第一批走查 1190 × 730 和 860 × 580 两种窗口。第二批并排比较 Now 首屏、一次追问后的线程、助理弹窗；第三批比较同一个截止日在只读、编辑、等待、冲突、未知五态下的变化。
- 用同一份退款样例完整操作「打开会议原文 → 返回 → 关注 → 收到验收进展 → 打开客户答复任务」。对照截图检查信息先后，用测试核对对象身份、选区、草稿和状态。
- 连接、设置和定时任务分别截取离线、只读与长名称场景。正式 App 中用键盘和 VoiceOver 核对任务名、最近运行结果、运行按钮指向和关闭详情后的焦点。
- 自动测试通过仅记录为行为通过。字体、层级和表面对照规范逐屏核验，VoiceOver 单独记录实测结果。

本轮基线的原型与 UI 测试已通过。首个设计交付物取「Now 首屏及一次追问」宽窄窗样张，共用样式可在这一小段完整流程中先行定稿。

## 实施记录

- 已落地五种文字角色、主区和导航层级、对话的单层编辑边界、可键盘打开的来源引用，以及截止日只读与编辑状态。
- 连接的详情展开和来源任务进入同一行。设置改为表单分组，区分可选模型、未配置资料与演示信息。定时任务行使用最小高度，名称完整值可通过提示查看。
- 基线截图位于 `tmp/ui-baseline`。改造后的截图位于 `tmp/ui-optimized`，其中包含 Now 首屏、追问、宽窄窗和五种截止日状态。
- 原型交互回归、全仓 Go 测试、vet、格式与架构检查已通过。打包 App 的 VoiceOver 实测待补。
- 文案走查后，Now 的历史进展合并为可打开的任务引用，来源断开时就地显示数据时效。助理空对话提供当前任务引用，回复仅陈述已知状态。
