# Apilot macOS 界面规范

本规范用于浅色 macOS 工作台的文字设计、组件实现和原型评审。窗口组合、控件选择、焦点与恢复行为沿用 [macOS App UI 指南](guides/macos-app-ui-guide.zh-CN.md)。每个页面先写清用户要判断的事、所需对象、可用动作和反馈，再决定布局。集合、详情和关系的梳理方法见[信息页面指南](guides/fe-page-guide-antd.md)。

## 窗口结构与区域

| 区域 | 放什么 | 布局与行为 |
| --- | --- | --- |
| 窗口工具栏 | 设置、全局助理、原型调试 | 高度基线 50 pt，保留系统窗口按钮和拖动区。全局命令位置稳定。Apilot 后显示当前路径。助理使用主窗口弹窗，设置使用独立窗口，调试从右上图标展开 |
| 导航侧栏 | Now 会话、任务、连接、定时任务、用量 | 宽 188 pt，可收起。图标与文字共用一行，选中底色标出当前去向 |
| 状态栏 | 同步、最近确认和本地运行状态 | 固定于主窗口底边，点击同步状态可查看连接 |
| 主内容 | 当前页面的消息、集合或对象 | 内边距 16 pt。集合按可用宽度对齐列。对话正文最大宽度以 688 pt 起步，输入区与消息列对齐 |
| 页面工具 | 当前集合的搜索、筛选、排序 | 搜索和筛选紧贴集合上方，排序放在对应列头。切换详情时保留查询、选区和滚动位置 |
| 对象详情 | 对象名称、来源事实、证据和可执行动作 | 可用宽度充足时在列表右侧，窄窗改到列表下方。可从工具栏收起，用 `o` 打开。选区和草稿随布局保留 |

当前实现的窗口尺寸作为第一轮走查基线，宽窗 1190 × 730 pt，窄窗 860 × 580 pt。断点的判断依据是任务名、来源、关键状态是否仍可辨认。系统控件随文字和窗口变化保留可读内容，自定义行允许增高。

| 页面 | 第一眼读什么 | 操作放在哪里 |
| --- | --- | --- |
| Now | 刚发生的变化、受影响的工作，以及需要我判断的事 | 进入即有简报。依据紧跟对应判断，建议动作随消息出现。后续变化追加到线程，底部保留追问入口 |
| 任务 | 每行一个任务，横向比较状态、优先级、来源和截止日 | 行选择控制浏览。详情承载原文与可写字段。窄窗用方向键浏览、Return 打开 |
| 连接 | 连接实例名、覆盖范围、健康状态、最近确认时间 | 异常行就地提供恢复动作。身份、同步方式与能力在展开区查看 |
| 定时任务 | 自动化名称、运行计划、下次运行和最近结果 | 手动运行在对应行，启停与执行细节归入对象详情 |

## 字体与空间

采用 macOS 系统 UI 字体及系统中文回退。下表是 Apilot 自绘内容的角色，原生控件优先使用 MyGo 官方组件的系统指标。

| 角色 | 字号与字重 | 示例 |
| --- | --- | --- |
| 当前对象或页面标题 | 17 pt，半粗 | 详情中的任务名称；当前去向已清楚时可直接从内容开始 |
| 分组标题、简报首句 | 15 pt，半粗 | 需要用户判断的变化 |
| 连续阅读 | 15 pt，常规 | 助理回复、来源原文；长文自然折行 |
| 操作与数据 | 13 pt，常规 | 行标题、表格值、字段、按钮 |
| 辅助信息 | 12 pt，常规 | 时间、位置、运行计划 |

间距使用 4、8、12、16、24 pt。标题和副标题间 4，相关控件间 8，区域内不同元素间 12，内容边距和分组间 16，独立消息间 24。单行集合以 32–36 pt 起步，双行以 48–56 pt 起步。图标通常 16 pt，独立图标按钮命中区至少 28 × 28 pt。标题、正文和相关操作沿同一条文本边线排列。

## 色彩与表面

页面按语义取色。下列浅色值来自共享主题，品牌色调整集中在[主题实现](../../internal/ui/components/theme.go)。

| 角色 | 主题与颜色 | 使用位置 |
| --- | --- | --- |
| 窗口底与内容面 | Background `#FCF9F7`、Surface `#FFFFFF` | 导航与详情底、主阅读与集合区域 |
| 主次文字 | Text `#30222E`、TextMuted `#74636F` | 对象名称和事实用主文字，时间与辅助标签用次文字 |
| 主动作与焦点 | Accent / Focus `#B5472E`、AccentText `#FFFFFF` | 当前决策的主按钮；键盘焦点用轮廓表达 |
| 选择与指针反馈 | Selection `#F7D9CF`、SurfaceHover `#F8EDE9`、SurfacePressed `#F2DED8` | 自绘行选中、悬停和按下。原生表格沿用系统选区与窗口失焦反馈 |
| 边界 | Border `#D2C2C7` | 持续区域之间的一条细分隔、输入控件的可编辑边界 |
| 业务状态 | Success `#087B72`、Warning `#9C6500`、Danger `#BB2441` | 已成功、需核对、失败。配合文字或符号表达结果，普通日期使用主文字 |

同一决策区最多一个实心强调动作。关联内容先用对齐和间距分组；独立对象、浮层或需要共同处理的冲突才单独围合。输入区保留一层可见编辑边界。品牌形象沿用 Apilot 飞行员，用于应用身份和合适的空状态；功能图标使用 SF Symbols，星光表示助理入口。

## 组件如何表达工作

- **引用和命令。** 引用写出用户认识的来源和位置，可点击或键盘打开。打开「客户会议 › 跟进事项」只查看依据，「关注退款验收」改变关注状态，二者用链接式引用和主按钮区分。
- **字段和状态。** 已确认的截止日用普通字段行。开始编辑时呈现编辑器；提交后原位列出来源确认值、拟写值及状态。冲突时再给出两种处理动作。
- **消息和输入。** 简报首句写出具体变化或决定。作者、时间按消息组展示；后续回复延续阅读顺序。输入框用于追问，常见决定提供直接选择。
- **图标和交互。** 纯图标命令提供动作名称和提示；行内命令包含目标对象。选择、焦点、悬停分别可辨。同步中保留最近确认内容，失败时在受影响的位置给出恢复入口。
- **复用。** 优先使用 MyGo 官方表格、选择器、滚动区和系统符号。原型和应用使用同一套展示组件；组件预览替换样例数据和状态，页面负责查询、路由和副作用。

分页控件固定在任务列表页脚，保持浏览时可达。页码和条目范围按同一份筛选、分组和排序后的集合计算。首尾页禁用对应的翻页动作，详情返回保留列表位置。

## 来源对象的操作与写入状态

工作台可以共用任务和来源对象的展示结构。当前连接状态、权限与来源能力共同决定可编辑字段、候选值和可执行动作。例如，GitHub Issues 的标签从当前仓库提供，Obsidian Tasks 的标签沿用所连接 vault 的范围及校验规则。

写入等待期间保留来源最近确认的值，并就地显示待确认状态。存在写入冲突时并列显示确认值与拟写值，明确用户可选的处理动作。权限不足、连接断开或结果未知时，在受影响的字段或操作旁说明原因及可用的恢复入口。

## 评审方法

1. 并排查看宽窄窗。读出当前对象、发生的变化和可执行动作，检查长中文标题、无截止日、无结果及来源断开时的布局。
2. 从 Now 打开两条不同依据，在详情关注，再回到原消息。核对来源位置、已关注状态、输入草稿和阅读位置。
3. 用键盘筛选任务、移动选区、打开详情、修改日期并返回。逐一查看待确认、冲突和结果未知，仍能读出原值、拟写值和恢复动作。
4. 在组件预览和实际页面切换同一组样例，比较字号、颜色、命中区、选中和禁用状态。在打包应用中用 VoiceOver 核对任务名、运行结果、按钮目标和焦点返回。
