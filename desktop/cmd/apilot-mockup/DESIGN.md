# Apilot macOS MVP 产品设计

## 文字设计

面向已经有工作来源的用户。一次典型使用从「发生了什么、需要我决定什么」开始，经过「依据可靠吗」，以「动作产生了什么结果」结束。用户可以在原平台完成工作，Apilot 在下一次同步后反映进展。首发用一个真实来源验证，原型用已有的 Obsidian 和团队工单样例。

| 入口 | 用户的问题 | 组织方式 |
| --- | --- | --- |
| Now | 此刻有什么需要我看？ | 进入即呈现一条提前准备的简报消息，交代当前最值得关注的事、依据与可选动作。用户可以直接选择，也可以继续追问。来源有新进展时，以后续消息接续这段对话。 |
| 任务 | 我想找一条记录，核对或修改它。 | 表格负责集合浏览。选中后查看任务状态、原始内容、关注及可写字段。来源确认值和待写值各自可见。 |
| 连接 | 我的数据还新吗？出了问题到哪处理？ | 连接先展示来源、范围、状态和最近确认时间。账号与能力作补充。同一连接可直接查看其任务。 |
| 定时任务 | 我的自动化什么时候运行、结果怎样？ | 延续本地自动化的计划、运行结果、启停与手动运行；保留独立入口。 |
| 全局助理 | 围绕当前上下文，我还想弄清楚什么？ | 入口全局可用。对话顶部显示当前对象，回复和引用可核对。关闭后继续原来的工作。 |
| 设置 | 助理和插件使用什么配置？ | 独立窗口按模型、助理资料、扩展组织。 |

### 三条必须走通的路径

1. **需判断 → 依据 → 关注**。从 Now 就地打开验收任务的详情，能看到引用片段；关掉详情仍留在 Now。关注后，消息的操作区显示关注状态。忽略只处理本次建议。来源验收通过后，出现针对客户答复的新建议；验收完成与客户答复仍待处理同时成立。
2. **任务 → 修改 → 确认**。在已筛选的表格中打开任务，保存一个截止日；行内显示确认值和回写状态。详情关闭后筛选与排序仍在。正常演示中来源稍后确认；冲突和结果未知由调试 Pane 注入。
3. **连接 → 核对来源**。看到来源断开时仍可读最近确认的数据，从连接直接打开该来源任务。重新连接后刷新健康信息，任务的历史确认时间随各自的新记录更新。

### 状态和边界

- 「待你判断」是一条尚未处理的分析，「正在关注」是用户建立的持续跟进。取消关注与收起分析各有作用，来源对象仍能查询。
- 最近变化的时间取该变化被确认的时间。连接重新确认成功只影响连接健康，历史变化时间保留。
- 来源状态与同步状态分开。等待确认时表格保留旧值，详情给出提议；冲突由用户选择。
- 本轮范围是已接入来源下的产品结构与 UI。首次接入、批量操作、复合绑定管理和完整自动化编辑继续留在各自后续工作里。

### 文字走查

用退款验收和回复客户走查，发现两个会误导用户的混用。其一，关注成功后原建议仍像待办，应在同一条消息中把建议动作换成关注状态。其二，历史动态借用了连接的最近确认时间，重连会让旧变更看起来刚发生。两处都应在演示数据和界面实现中分开。再用「从 Now 核对证据」和「从已筛选列表改截止日」验证返回路径，两条都需要保留正在工作的页面，适合复用同一个详情区域。

## UI 布局

```text
窗口工具栏    Apilot                            设置   助理   调试
┌───────────┬──────────────────────────────┬────────────────────┐
│ Now       │ Now / 任务 / 连接               │ 详情            ×   │
│ 任务       │                              │ 对象标题             │
│ 连接       │ 当前页面主体                     │ 来源 · 状态 · 优先级    │
│ 定时任务    │                              │ 原文片段             │
│           │                              │ 关注／可写字段         │
└───────────┴──────────────────────────────┴────────────────────┘
```

- 侧栏保持四个去向，窗口工具栏图标全局可用。助理、设置各有自己的窗口。调试使用右上角锚定 Pane，ChangeTag 默认关闭。
- Now 主区为可滚动的对话，底部固定输入框。第一条是带时间的简报，正文内呈现关键变化，依据和动作随消息展示。打开详情保留对话；随后发生的来源变化追加为消息。
- 任务的工具条放搜索、状态与来源筛选。紧凑的列头和数据行对齐。选中任务时才显示详情。宽窗中表格和详情并排，各自滚动，窄窗由详情替换内容区。返回后恢复选区、搜索和滚动。
- 详情标题、事实、证据及编辑依次向下。装饰限于一个品牌强调色、SF Symbols 和细分隔。业务状态与同步结果均有文字。保留 Apilot 原有浅色配色和系统字体。
- 连接用行标题、健康状态和明确的操作。断开连接的重试保留文本，正常连接的刷新使用图标。定时任务将日程翻成可读文字，具体规则和运行命令放在详情。

宽窗检查三列是否互不挤占，窄窗检查返回是否找得到。用同一组数据查看待判断、关注、来源确认、回写冲突和连接断开。截图用于确认布局与可达性。
